## Agent tooling

Generated by the ingestio_examples hub for ingestio `0.5.0`, and regenerated by
it; no stage of the workflow changes them.

| Path | What it is |
|---|---|
| `.claude/agents/` | The five agents of the [workflow](workflow.md): `planner`, `tester`, `documenter`, `implementer`, `validator`. |
| `.claude/kb/ingestio.md` | The guidance on ingestio, stamped with the version it was generated for. |
| `.claude/hooks/guard_git_writes.py` | Blocks git and GitHub writes from every agent. |
| `.claude/hooks/restrict_writes.py` | Keeps each agent's file edits inside its stage's paths. |
| `.claude/settings.json` | Permissions, attribution off, the hook above, and the hub's instruction files excluded from the job's sessions. |
| `.pre-commit-config.yaml` | Rejects co-author trailers and AI-generation footers in commit messages. |
